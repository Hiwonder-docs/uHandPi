# 6.PC Action Editing Course

## 1. PC Software Introduction

### 1.1 **Turn on PC Software**

**1.1.1 Turn on with desktop icon (recommended for beginners)**

(1) Double-click the uhandpi icon on the desktop.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/1.1/image1.png"  />

(2) Click “Execute” in the prompt interface to open PC.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/1.1/image2.png"  />

**1.1.2 Turn on with command line**

(1) Click the icon<img src="../_static/media/9.upper_computer_action_editing_course/1.1/image3.png"   />on the left upper corner to open the command line terminal.

(2) Then input the following command line in the terminal window to open PC.

```commandline
python3 /home/pi/uhandpi_software/uhandpi_control/main.py
```

## 2. Call Action Group

The robotic hand comes with built-in action groups stored in the following path at the time of manufacturing: **/home/pi/uhandpi/action_groups**

We can use the host computer software to view and call its built-in actions. The specific steps are as follows:

### 2.1 Operation Steps

(1) Power on the robot and use VNC Viewer to connect to the remote desktop.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image1.png"  />

(2) Double click the uhandpi icon on the desktop.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image2.png"  />

(3) Click “Execute” on the pop-up interface to open PC.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image3.png"  />

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image4.png"  />

(4) Next, click “Open Action File” key to select the action group required to be executed. And click “Open” again.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image5.png"  />

(5) At this point, the action details list will display the action group's file path and servo values for each action. The following image shows only a partial screenshot of the actions.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image6.png"  />

(6) Click the "Run" button to execute all actions currently listed in the action details. If you want to repeat the current action group, you can check the "Loop" option.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image7.png"  />

### 2.2 Import External Action Groups

To call external actions through the host computer, you can follow these steps. This section takes importing **“22_hand_heart.d6a”** action group as example. Note: the action group files must end with “.d6a”.

(1) Insert the USB flash drive containing the action files into any USB port on the Raspberry Pi motherboard. Copy the action group files to the system desktop by using copy-paste as pictured:

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image8.png"  />

(2) Click icon"<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image9.jpeg"  /> "to locate the “/home/pi/uhandpi/action_groups” path. Place the action group under this path as pictured:

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image10.png"  />

(3) Double click the uhandpi icon on the desktop.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image2.png"  />

(4) Click “Execute” in the pop-up interface to open PC.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image3.png"  />

(5) NEXT, click “Open” key to select the action group required to be executed. And click “Open” again.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image11.png"  />

(6) At this time, the action detailed list displays the value of the new imported action group and running time.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/2.1/image12.png"  />

## 3. Action Group Editing Learning

The values set in this document are for reference only, and users can adjust them according to their actual situation.

### 3.1 Program Purpose

Create an action group that implements the action of “closing and opening the hand”.

### 3.2 Operation Steps

**3.2.1 Action designation**

(1) Click “Open Action File” and select “15_5_12345” action group. Then click “Open” to set an initial position to the robot.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image1.png"  />

(2) In the action detailed list, click the key next to action 1 to execute it. That synchronize the servo angle information with the servo area on the left.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image2.png"  />

(3) Slide the sliders for servos 1 to 5 to move the fingers of the robotic hand downwards. The specific values are as shown in the following image:

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image3.png"  />

(4) Set the time to 1000ms, then click "Add Action" to obtain the second action.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image4.png"  />

(5) To make the entire set of actions more cohesive and smooth, we add a transition action after setting each action. Based on the previous action, modify the time to 200ms, then click "Add Action" again to obtain the third action.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image5.png"  />

(6) Next, open the robot hand. Slide the sliders 1-5. The specific value is as pictured:

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image6.png"  />

(7) Set the time to 400ms, then click “Add Action” to obtain the fourth action.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image7.png"  />

**3.2.2 Action saving**

To facilitate later debugging and management, you can save the actions. Click the "Save Action File" button, here naming it "16_center_move" as an example, then click "Save".

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/3.1/image8.png"  />

## 4. Integrate Action Group File

:::{Note}
This section explains with the examples of action groups "20_no" and "23_ok". You can view the demonstration video in the directory.
:::

### 4.1 Program Purpose

Learn the function of integrate action to realize the merging between action groups.

### 4.2 Operation Steps

(1) Open PC and click “integrate action files”.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image2.png"   />

(2) Select 23_ok action group in the popped-up interface, and click “Open”.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image3.png"  />

(3) Now you can see the whole action of 23_ok in the action list.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image4.png"  />

(4) Next, click “integrate action file” again, select “20_no” action group and click “Open”.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image5.png"  />

Now, the action details list shows the full set of actions from both the "23_ok" and "20_no" action groups, seamlessly connected from start to finish.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image6.png"  />

(5) Click “Run” to execute the concatenated new action group online.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image7.png"  />

(6) Click “Save Action File” to save the integrated new action group to facilitate the later debugging. Here we name the new action group “hiwonder”.

<img class="common_img" src="../_static/media/9.upper_computer_action_editing_course/4.1/image8.png"  />
